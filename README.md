# 後継機種調査システム

設備更新のとき、古い機器の型番から**後継機種・寸法比較・懸念点・必要工具・材料・現場確認チェックリスト**をまとめます。

## 決まりごと
- 使う情報は**メーカー公式資料だけ**（公式サイト・仕様書・外形図・施工説明書）。
- 通販サイト・ブログ・Q&Aサイトは使いません。
- 資料で確認できない項目は「**未確認（メーカー確認要）**」と表示します。推測では埋めません。
- すべての数値に出典（資料名・ページ）が付きます。

## 使い方（3ステップ）
1. このリポジトリで Claude Code を開く（スマホの Claude アプリからでも可）。
2. 次のどちらかを送る。
   - **銘板の写真**（型番・メーカー名が読めるように正面から、ピントを合わせて）
   - **メーカー名と型番**（例：「メーカー名　型番」の形で、銘板の表記どおりに）
3. 結果を確認し、「7. 現場確認チェックリスト」を現場で一つずつ確認してから施工する。

結果は `調査結果/` フォルダに日付つきで保存され、次回同じ機種を調べるときに参照されます。

## 送るときのコツ（間違い防止）
- 型番は**銘板の表記どおり**に、末尾の記号まで全部送る（末尾の違いで電源・色・仕様が変わることがあります）。
- 写真で読めない文字があると、Claude が聞き返します。推測で進めることはありません。
- 同じ場所に複数台ある場合は、1台ずつ型番を確認してください。

## 結果の見方
| 章 | 内容 |
|---|---|
| 1. 結論 | 後継機種と、そのまま交換できるか |
| 2. 寸法比較 | 外形・取付穴・ピッチ・重量の新旧比較と差 |
| 3. 電気仕様 | 電源・消費電力・ブレーカー容量・配線方式 |
| 4. 懸念点 | 資料で確認できた新旧の違い |
| 5. 必要工具・材料 | 施工説明書に書かれた工具・部材・別売部品（品番つき） |
| 6. 施工手順の要点 | 施工説明書の手順と注意事項 |
| 7. 現場確認チェックリスト | 施工前に現場で確かめる項目 |
| 8. 出典 | 使った資料の一覧 |

> 現地の実寸法・既設配線は施工前に現場で確認してください。
