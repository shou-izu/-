# 現場カレンダー ⚡

電気工事チーム（5人前後）向けの、**話すだけで予定が入って、みんなで共有できる**スマホ用アプリです。
TimeTree の「すぐ入れられる・写真がのせられる・みんなが見やすい」ところだけを残して、
**電話の受け漏れ・報告漏れを防ぐ仕組み**を足しました。

## できること

| | |
|---|---|
| 🎤 **声で予定を登録** | 大きなマイクボタンを押して「明日の10時、山本建設さんから、駅前ビルの照明交換、佐藤さん」と話すだけ。日付・時間・取引先・現場・担当・内容を自動で読み取ります。話し終わって4秒たつと自動で登録されるので、手がふさがっていても入れられます。 |
| 👥 **全員で共有** | 登録した予定は数秒〜15秒で全員のスマホに反映。担当ごとに色分けされ、名前でしぼりこみもできます。 |
| 📷 **施工報告** | 予定を開いて「写真を撮る」→「完了にする」。報告コメントも声で入れられます。写真は自動で小さくしてから送ります。 |
| ⚠️ **要確認（もれ防止）** | ・日にちが過ぎたのに完了していない予定（報告待ち）<br>・日時が決まっていない電話メモ（日時未定）<br>・1週間以内で担当が決まっていない予定（担当未定）<br>をまとめて表示し、件数をバッジで出します。 |
| 📵 **電波が悪くても大丈夫** | 圏外で登録しても端末に保存しておき、電波が戻ったら自動で送ります。 |

### 声で言える言い方の例

- 日付：今日／明日／あさって／昨日／金曜／来週水曜／再来週月曜／10月3日／25日
- 時間：10時／3時半（1〜6時は午後あつかい）／午後1時から3時まで／午前中／朝一
- 担当：メンバーの名前（「佐藤さん」など）／「全員」
- 取引先：「〇〇建設」「〇〇工務店」「〇〇電設」など、または「〇〇さんから」
- 現場：「〇〇様邸」「〇〇ビル」「〇〇マンション305号室」「現場は〇〇」など

日時を言わなかった予定も消えずに「要確認」に入るので、電話を受けたらまず声で入れておけばOKです。

## 動かし方

Node.js 18 以上だけで動きます（追加のインストールは不要）。

```bash
TEAM_PASSCODE=好きな合言葉 npm start
# → http://localhost:3000
```

| 環境変数 | 意味 | 初期値 |
|---|---|---|
| `TEAM_PASSCODE` | チームの合言葉（ログインに使う） | `1234` |
| `PORT` | ポート番号 | `3000` |
| `DATA_DIR` | 予定と写真を保存するフォルダ | `./data` |

予定は `data/db.json`、写真は `data/photos/` に保存されます。**このフォルダをバックアップしてください。**

### みんなのスマホで使うには

音声入力とホーム画面への追加には **https のURL** が必要です。次のどちらかがおすすめです。

1. **クラウドに置く**（Render / Railway / VPS など）
   - 起動コマンド `npm start`、環境変数 `TEAM_PASSCODE` を設定
   - 写真とデータが消えないよう、永続ディスクをつけて `DATA_DIR` をそこに向ける
2. **事務所のパソコンで動かす** ＋ Cloudflare Tunnel などで https のURLを発行

URLを全員に送り、スマホで開いて
- iPhone：Safari の共有ボタン →「ホーム画面に追加」
- Android：Chrome のメニュー →「ホーム画面に追加」

でアプリのように使えます。はじめに合言葉を入れて、自分の名前を選びます（メンバーは設定画面で追加・色変更できます）。

### 音声入力について

- Android の Chrome、iPhone の Safari では、アプリ内のマイクボタンでそのまま聞き取ります。
- 聞き取りに対応していないブラウザでは、文字の欄が開くので、キーボードのマイクボタンで話してください。読み取りの仕組みは同じです。

## 開発

```bash
npm test   # 音声の文章から予定を読み取る部分のテスト
```

- `server.js` … サーバー（予定・写真・メンバーの保存、合言葉ログイン）
- `public/parse.js` … 話した文章から日時・担当・取引先・現場を読み取る
- `public/app.js` … 画面の動き（カレンダー、音声入力、要確認、写真報告、圏外時の送信待ち）
