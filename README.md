# 声メモ

話すだけですぐメモが取れる音声メモアプリ（PWA）。

## 使い方

1. 大きなマイクボタンを押して話す（PC ではスペースキーでも可）
2. もう一度押すと、文字起こしされたメモが保存される
3. メモはタップしてそのまま編集できる。コピー・共有・削除・検索にも対応

- 「音声も保存」にチェックを入れると、録音した音声も一緒に保存されます
- データはすべて端末内（IndexedDB）に保存され、外部サーバーには送信しません
  （ただし文字起こしはブラウザ標準の音声認識を使うため、ブラウザによってはその提供元のサーバーで処理されます）
- ホーム画面に追加すると、アプリとして起動できます

## 動かし方

マイクを使うため HTTPS か localhost で開く必要があります。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages で公開すれば、スマホからそのまま使えます。

## 対応ブラウザ

- 文字起こし: Chrome / Edge / Safari（Web Speech API）
- 非対応ブラウザ（Firefox など）では音声の録音のみ保存されます
