# YUECT コーポレートサイト（試作版）

電気・空調・消防・建物メンテナンスの設備会社「YUECT」のホームページです。
問い合わせが多い設備会社サイトの定番構成（電話番号を常に表示／無料見積りボタンを何度も出す／選ばれる理由／施工実績／お客様の声／依頼の流れ／FAQ）にしています。

## 見方
`index.html` をブラウザで開くだけで表示されます。

## ファイル構成
- `index.html` … ページの中身（文章はすべてここ）
- `assets/css/style.css` … デザイン（先頭にブランドカラー）
- `assets/js/main.js` … メニュー・実績の絞り込み・数字のアニメーション
- `assets/img/` … ロゴマーク（SVG）・背景写真

## 仕事内容が変わったときに直す場所
| 変えたいこと | `index.html` のコメント |
|---|---|
| 事業内容（6つのカード） | `事業内容` |
| お悩みリスト | `お悩み` |
| 選ばれる理由 | `選ばれる理由` |
| 施工実績 | `施工実績`（`data-cat` とフィルターボタンの `data-filter` を合わせる） |
| 会社情報・住所 | `会社概要`・フッター |
| 電話番号 | `080-1234-5678` / `tel:0801234567` を一括置換 |

## 公開前にやること
- 数字・施工実績・お客様の声は **仮のサンプル** です。実際の内容に差し替えてください。
- 問い合わせフォームは仮で `mailto:` にしています。Formspree や Googleフォーム等に差し替えると確実に届きます。
- LINEボタンのリンク（`href="#"`）を公式アカウントのURLに変更してください。
- ロゴはSVGで再現した簡易版です。正式なロゴデータがあれば `assets/img/` を差し替えてください。
