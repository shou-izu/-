## 実装済みのSEO対策
- **事業ごとの専用ページ**（「横浜 電気工事」など、キーワードごとに上位表示を狙える作り）
- 全ページに固有の `title`／`description`／`canonical`
- **構造化データ（JSON-LD）**：会社情報（Organization）、地域の事業者（Electrician・HVACBusiness／住所・営業時間・対応エリア）、サービス（Service）、よくある質問（FAQPage）、パンくず（BreadcrumbList）
- OGP・Twitterカード（LINEやSNSでシェアしたときに画像付きで表示）
- `sitemap.xml`・`robots.txt`・`site.webmanifest`・favicon・apple-touch-icon
- 見出し構造（h1は各ページ1つ）、画像のalt、パンくずリスト、内部リンク
- 表示速度：WebP画像、画像サイズ指定、遅延読み込み、メイン画像の先読み
- スマホ対応・アクセシビリティ（キーボード操作、スキップリンク、動きを減らす設定への対応）

## 公開前に必ずやること
1. **ドメイン**：`https://yuect.co.jp/` で書いています。違う場合はすべてのファイルで一括置換してください。
2. **住所・電話・代表者名**：`〒221-0000`、`〇〇区〇〇町1-2-3`、`090-1234-5678`、`山田 太郎` は仮の情報です。HTML内の構造化データ（`application/ld+json`）の中の値も同じく書き換えてください。
3. **仮のコンテンツ**：実績の数字、施工実績、お客様の声、料金目安はサンプルです。実際の内容にしてください（事実と違う内容はGoogleの評価も下がります）。
4. **問い合わせフォーム**：`https://formspree.io/f/XXXXXXXX` を、Formspree（無料）で発行したURLに置き換えてください。
5. **LINEボタン**：`href="#"` を公式LINEのURLに。
6. **Googleマップ**：会社概要の「Googleマップ埋め込み予定」を埋め込みコードに置き換え。
7. `sitemap.xml` の `lastmod` を公開日に更新。

## 公開した後にやること（集客に大きく効きます）
- **Googleビジネスプロフィール**に登録（「横浜 電気工事」で地図枠に出るために最重要）。住所・電話番号・会社名はサイトと完全に同じ表記にする
- **Google Search Console** に登録して `sitemap.xml` を送信
- Googleアナリティクス（GA4）を設置
- 施工実績を写真付きで**毎月追加**する（更新頻度と実績の量が評価につながります）
- お客様にGoogleの口コミを書いてもらう

## 仕事内容が変わったとき
- トップページの事業内容：`index.html` の `事業内容` のところ
- 事業ページの追加：`services/` の中のファイルをコピーして書き換え、`sitemap.xml` とメニュー（各ページのヘッダー・フッター）にも追加
- 色：`assets/css/style.css` の先頭（YUECTブルー・ネイビー・シルバー・ブラック）
