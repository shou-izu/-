# 後継機種調査（電気工事・設備更新用）

## 最重要ルール：確実な情報だけを出す
- 情報源は**メーカー公式**に限る：メーカー公式サイトの後継品・代替品検索、生産終了品のお知らせ、商品ページ、仕様書・外形図・施工説明書・取扱説明書のPDF。
- 卸サイト、通販サイト、ブログ、Q&Aサイト、まとめサイトは**参考にも使わない**。
- すべての数値・記述に出典（資料名・ページ）を付ける。出典のない記述は書かない。
- 公式資料で確認できなかった項目は推測で埋めない。「**未確認（メーカー確認要）**」と書く。
- 「〜と思われます」「一般的には」「おそらく」といった表現は使わない。
- 価格は変動するため、聞かれない限り書かない。

## 手順
1. **型番を確定する**
   - 銘板写真なら型番・メーカー・製造年を読み取る。読めない文字があれば推測せず、その部分を聞き返す。
   - 型番が途中までしかない、または複数の候補があるときは、候補を示して確認する。
2. **生産状況と後継品を調べる**
   - メーカー公式の後継品・代替品検索や生産終了品ページで調べる。
   - 公式の区分をそのまま書く（「後継品」「代替品」「該当なし」など）。メーカーが後継品を示していない場合は、自分で選ばず「公式の後継品指定なし」と書く。
   - 後継品が複数ある場合（色違い・電源違い・オプション違い）は、すべて並べ、旧機種と仕様が一致するものを公式資料の記載で示す。
3. **旧機種と新機種の資料を両方取得する**
   - 外形図、仕様書、施工説明書のPDFを実際に開いて読む。検索結果の抜粋だけで数値を書かない。
   - 旧機種の資料が公開終了している場合は、その旨を書く。
4. **数値を照合する**
   - 寸法・電気仕様は、表に書く前に資料の該当箇所をもう一度確認する。
   - 差（新−旧）は計算して書く。片方が未確認なら差も「未確認」。
5. **下の形式でまとめ、`調査結果/` に保存する**
   - ファイル名：`調査結果/YYYY-MM-DD_メーカー_旧型番.md`
   - 同じ旧型番の過去ファイルがあれば読んでから調べ、変更点（後継品の変更・資料の改訂）があれば書く。

## 出力形式（スマホで読みやすく、簡潔に）

### 1. 結論
- 旧機種：メーカー／型番（生産状況）
- 後継機種：型番（公式区分：後継品／代替品）
- そのまま交換できるか：「取付寸法・電気仕様とも資料上一致」「差異あり（4. 懸念点参照）」「未確認項目あり」のいずれか

### 2. 寸法比較
| 項目 | 旧機種 | 新機種 | 差 |
|---|---|---|---|
| 外形（幅×高さ×奥行） | | | |
| 埋込穴・取付穴寸法 | | | |
| 取付ピッチ | | | |
| 重量 | | | |
| ダクト径・接続口径（該当する場合） | | | |
資料にない項目は「未確認（メーカー確認要）」。

### 3. 電気仕様
電源、消費電力、定格電流、指定ブレーカー容量、配線方式（結線、アース、端子形状）。施工説明書・仕様書の記載のみ。

### 4. 懸念点
資料から確認できた差異だけを書く。例：取付穴寸法の変更、重量の増加、配線方式・端子の変更、別売部品（アダプター・取付枠など）の要否とその品番、リモコン・制御機器の互換性、必要な離隔距離、受注生産品かどうか。

### 5. 必要工具・材料
- 施工説明書に記載された工具・部材・別売部品（品番つき）だけを書く。
- 施工説明書に工具の記載がない場合は「施工説明書に記載なし」と書く。

### 6. 施工手順の要点
- 施工説明書に記載された手順を、番号付きで短く書く（ページ番号つき）。
- 施工説明書に「注意」「警告」として書かれている事項は省略せず書く。
- 施工説明書を確認できなかった場合は「施工説明書未確認」と書き、手順は書かない。

### 7. 現場確認チェックリスト
施工前に現場で確かめる項目を `- [ ]` で並べる。2.〜4. の差異と未確認項目から作る。例：
- [ ] 既設の埋込穴寸法を実測：○○mm（新機種の必要寸法 ○○mm）
- [ ] 既設ブレーカー容量：○○A 以上か
- [ ] 別売部品 ○○（品番）を手配済みか

### 8. 出典
使った資料をすべて列挙する（資料名・URL・確認日）。

## 最後に必ず添える一文
「現地の実寸法・既設配線は施工前に現場で確認してください。」
