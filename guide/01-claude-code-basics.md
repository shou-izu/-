# Claude Code 仕事で使うための基本ガイド

> 最終更新: 2026-09-28 ／ 情報源は末尾参照

## 1. Claude Code とは

Anthropic が提供する「AIエージェント型」の開発ツール。チャットで答えるだけでなく、
**ファイルを読む・書く・コマンドを実行する・GitHub に PR を出す** ところまで自分で進めてくれる。

使える場所:

| 場所 | 向いている使い方 |
| --- | --- |
| ターミナル (CLI) `claude` | 本格的な開発。一番機能が多い |
| デスクトップアプリ (Mac/Windows/Linux β) | 画面を見ながら作業。内蔵ブラウザ・iOSシミュレータ・コンピューター操作 |
| Web / スマホアプリ (claude.ai/code) | クラウドで作業させて放置。外出中でも指示・確認できる ← 今あなたが使っているもの |
| VS Code / JetBrains 拡張 | 普段のエディタの中で使う |

料金: Pro / Max / Team などの Claude サブスクで使える。まず Pro で始め、
使用量の上限に頻繁に当たるようになったら Max を検討、が定番。

## 2. まず覚える操作（これだけで8割の仕事ができる）

1. **やりたいことを日本語で具体的に書く**
   - 悪い例: 「サイト作って」
   - 良い例: 「美容室のLPを1ページで。スマホ対応、予約ボタンはLINEへ、色は白とベージュ、
     セクションは ヒーロー/メニュー/料金/スタッフ/アクセス。HTMLとCSSだけで」
2. **`CLAUDE.md` を作る** (`/init`) — プロジェクトのルール（言語、口調、禁止事項、
   テスト方法）を書いておくと毎回説明しなくて済む。
3. **Plan モードで先に計画させる** — 大きな作業は「まず計画だけ出して」→確認→実行。
   手戻りが激減する。
4. **`/rewind` で巻き戻し** — 失敗したら戻せる。怖がらず試してよい。
5. **`/usage` で使用量を確認** — 何が上限を消費しているか分かる。
6. **スキル (Skills)** — よくやる作業手順を保存して `/名前` で呼び出せる。
   「毎回同じ指示をしている」と気づいたらスキル化する。

## 3. 2026年の重要機能（稼ぐ視点での使いどころ）

| 機能 | 何ができる | 仕事での使いどころ |
| --- | --- | --- |
| **Auto mode**（Pro以上で既定） | 安全な操作は確認なしで進む | 放置して任せられる時間が増える |
| **Routines（定期実行）** | 毎日/毎週、クラウドで自動実行 | 日次レポート、情報収集、記事下書きの自動化 |
| **Artifacts** | 作ったものを共有できるWebページとして公開 | 顧客へのデモ・提案資料・ダッシュボード |
| **サブエージェント / 並列作業** | 複数の作業を同時進行 | 大量の記事・ページ・データ処理を短時間で |
| **`/code-review`・`/ultrareview`** | バグをAIが探す | 納品前の品質チェック（信頼＝リピート） |
| **Computer use / 内蔵ブラウザ** | 画面を操作して動作確認 | 作ったサイトやアプリの動作確認を自動化 |
| **`/design`（プレビュー）** | UIの案を複数出して選んだものを実装 | デザイン提案→実装を一人で完結 |
| **MCP コネクタ** | Gmail・カレンダー・GitHub等と連携 | 事務作業の自動化、クライアント業務の効率化 |
| **Plugins / マーケットプレイス** | 機能を追加・配布できる | 自作プラグインを作って売る・配布する道も |

## 4. 安全に使うための注意

- 顧客の機密情報・パスワードを貼らない。APIキーは環境変数で。
- AIが書いたものは**必ず自分で動作確認してから納品**。ここを省くと信用を失う。
- 著作権・景表法・薬機法など、記事や広告の内容は人間が最終チェック。
- クラウドソーシングの規約（AI利用の可否・申告）を確認する。
