# Claude を「AI管理部」にする使い方
### 人事・総務・財務・オペレーション・管理の代わりをさせる

> 最終更新: 2026-09-28

## 考え方: 「チャット相手」ではなく「部署」として設計する

Claude に毎回その場で頼むだけだと、ただの便利なチャットで終わります。
管理部の代わりにするには、人間の部署と同じ **4つの部品** を用意します。

| 人間の管理部 | Claude での対応物 | 役割 |
| --- | --- | --- |
| 社内規程・業務マニュアル | **`CLAUDE.md`**（会社の基本ルール） | 会社名、決算月、締め日、承認ルール、言葉づかい、禁止事項 |
| 担当者ごとの手順書 | **スキル**（`/給与チェック` などで呼び出す手順） | 業務ごとの手順・チェック項目・出力形式 |
| 使う業務システム | **コネクタ（MCP）** | Gmail・Googleカレンダー・Google Drive・Slack・会計ソフト（freee など）とつなぐ |
| 毎日・毎月の定例業務 | **Routines（定期実行）** | 毎朝の受信整理、毎月の締め作業、期限アラート |

この4つを1つのフォルダ（リポジトリ）にまとめたものが「AI管理部」です。
このリポジトリの `back-office/` にひな形を置いてあります。

## 絶対に守る線引き

Claude は**下書き・集計・チェック・リマインド**まで。次の3つは人間が行います。

1. **お金を動かす**（振込、支払い承認、給与確定）
2. **外に出す**（メール送信、契約締結、役所への提出）
3. **判断が法律に関わるもの**（労務トラブル、税務判断、解雇・懲戒）→ 社労士・税理士・弁護士に確認

設定では、メールは「下書き作成まで」、会計ソフトは「読み取り中心」にしておくと安全です。
個人情報（マイナンバー、健康情報、給与明細）は必要最小限だけ渡してください。

## 部署別: そのまま使える指示文

### 人事（採用・入退社・評価）
| 業務 | 指示文の例 |
| --- | --- |
| 求人票作成 | 「経理スタッフ（パート、週3日）の求人票を作って。仕事内容・必須条件・歓迎条件・待遇・選考フローの順で。誇大表現は避けて」 |
| 応募者の一次整理 | 「このフォルダの応募書類を読んで、必須条件を満たすかを表にして。評価は根拠となる記載を引用して。合否は私が決める」 |
| 面接準備 | 「この候補者の職務経歴書から、確認すべき点と質問を10個。圧迫にならない聞き方で」 |
| 入社手続き | 「来月入社の2名について、入社前〜初月のチェックリストと、各期限をカレンダーに入れる案を作って」 |
| 評価面談 | 「この四半期の目標シートと実績メモから、評価コメントの下書きを。良い点・課題・次期目標の3段で」 |

### 総務（庶務・契約・備品・社内連絡）
| 業務 | 指示文の例 |
| --- | --- |
| 受信メール整理 | 「今朝のGmailを見て、要返信・要対応・情報のみ に分けて一覧に。要返信には返信の下書きを作って（送信はしない）」 |
| 契約書管理 | 「Driveの契約書フォルダから、更新期限・自動更新の有無・解約通知期限を表にして。90日以内のものを先頭に」 |
| 社内規程の作成・改訂 | 「在宅勤務規程のたたき台を作って。対象者、申請方法、費用負担、情報管理を入れて。法的な確認が要る箇所に印を」 |
| 社内通知 | 「年末年始休業のお知らせを、社内向けと取引先向けの2種類で」 |
| 備品・固定資産 | 「このCSV（備品台帳）から、購入から5年以上のPCと、担当者が退職済みの備品を抜き出して」 |

### 財務・経理
| 業務 | 指示文の例 |
| --- | --- |
| 請求書チェック | 「今月届いた請求書PDFを読んで、取引先・金額・支払期日・インボイス番号の表を作って。登録番号がないものは警告して」 |
| 経費精算チェック | 「この経費CSVを規程（CLAUDE.md参照）と照らして、上限超過・領収書なし・重複の疑いを一覧に」 |
| 月次の数字まとめ | 「会計ソフトのデータ（または試算表CSV）から、売上・粗利・販管費を前月比・前年同月比で。大きく動いた科目は理由の候補も」 |
| 資金繰り表 | 「入金予定と支払予定のCSVから、今後3か月の資金繰り表を週単位で。残高が◯万円を下回る週に印を」 |
| 売掛金の督促 | 「支払期日を過ぎた請求の一覧と、段階別（やわらかい→正式）の督促メール下書きを」 |

### オペレーション（業務の仕組み化）
| 業務 | 指示文の例 |
| --- | --- |
| 業務マニュアル化 | 「私が今から話す受注処理の流れを、手順書にして。分岐・例外・担当者を明記して」 |
| 定型作業の自動化 | 「毎週やっている『売上CSVを担当者別に分けて集計する』作業を、スクリプトにして。次から1コマンドで終わるように」 |
| 発注・在庫 | 「在庫CSVと過去3か月の出荷実績から、来週発注すべき品目と数量の案を」 |
| 業者比較 | 「この3社の見積書を比較表にして。金額・納期・保守・解約条件で。質問すべき点も」 |

### 管理・経営サポート（社長の右腕）
| 業務 | 指示文の例 |
| --- | --- |
| 朝のブリーフィング | 「今日の予定・要対応メール・期限が近いタスク・昨日の売上を1画面にまとめて」 |
| 週次レポート | 「今週の各部の数字とトピックから、経営会議用の1ページ報告を。課題と決めることを先に」 |
| 会議の議事録 | 「この文字起こしから、決定事項・宿題（担当・期限つき）・保留事項を。宿題はカレンダー登録案も」 |
| 期限管理 | 「年間の法定期限（年末調整、算定基礎届、労働保険の年度更新、決算・申告など）を当社の決算月に合わせて一覧に。※最終確認は専門家に」 |

## 定期実行（Routines）にすると「勝手に働く部署」になる

| いつ | 何をさせるか |
| --- | --- |
| 毎朝 | 受信メールの仕分け＋返信下書き、今日の予定と期限のまとめ |
| 毎週月曜 | 先週の売上・経費まとめ、今週の締切一覧 |
| 毎月1日 | 前月の請求書・経費チェック、未入金リスト、月次レポート下書き |
| 毎月25日 | 給与計算前のチェックリスト（入退社・勤怠の抜け漏れ確認） |
| 四半期ごと | 契約更新期限、規程の見直し候補、固定資産の棚卸し |

設定のしかた: Claude アプリの Code 画面で
「毎月1日の朝8時に、◯◯をするRoutineを作って」と頼めば作れます。

## 始める順番（おすすめ）

1. **1週目**: 自分が一番時間を取られている管理業務を3つ書き出す（例: メール、請求書、経費）。
2. **2週目**: その3つを Claude にやらせて、うまくいった指示文を `back-office/.claude/skills/` にスキルとして保存する。
3. **3週目**: Gmail・カレンダー・Drive などのコネクタをつなぎ、毎朝のまとめを Routine にする。
4. **4週目**: 時間がどれだけ減ったかを記録する（例: 請求書チェック 月4時間 → 30分）。

## これで稼ぐには

- **自分の会社・副業の管理コストを下げる**: 人を1人雇う代わりに月数千円〜のサブスク。最も確実なリターン。
- **中小企業向けに「AI管理部」の導入代行**: 上の4部品（CLAUDE.md・スキル・コネクタ・Routines）を
  その会社用に作って渡す。導入費＋月額保守の形にしやすい。
  4週目の「◯時間 → ◯分」という自分の実績が、そのまま営業資料になります。
- **士業・経理代行・社労士事務所の業務効率化**: 顧客が多い事務所ほど、同じ作業の繰り返しが多く効果が出やすい。
