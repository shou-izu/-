# Claude Code で稼ぐためのロードマップ

> 最終更新: 2026-09-28
> 注意: 「月◯万円」はネット上の事例であり、保証ではありません。大事なのは
> **小さく実績を作る → 発信する → 単価を上げる** の順番を守ることです。

## 稼ぎ方の候補（始めやすい順）

| # | 稼ぎ方 | Claude Code の役割 | 難易度 | 相場感の目安 |
| --- | --- | --- | --- | --- |
| 1 | **業務効率化ツール作成**（Excel/スプレッドシート自動化、CSV整形、GAS） | スクリプトを書いて動かす | ★☆☆ | 1件 5千〜5万円 |
| 2 | **LP・小規模サイト制作** | HTML/CSS/JS を生成・修正・動作確認 | ★★☆ | 1件 3万〜15万円 |
| 3 | **ブログ/SEO記事の制作・運用代行** | 構成→下書き→WordPress投稿を自動化 | ★☆☆ | 1記事 数千円〜、運用代行は月額 |
| 4 | **自分のメディア・ツールを作って収益化** | 小さなWebアプリ・ツールを量産 | ★★☆ | 広告/アフィ/サブスク（時間はかかる） |
| 5 | **AI導入支援・研修** | 中小企業に「Claude Code で業務をこう減らせる」を実演 | ★★★ | 1回 数万円〜、顧問契約 |
| 6 | **プラグイン/スキル制作** | 業種別の Claude Code スキルやプラグインを作る | ★★★ | まだ新しい市場 |

## 30日スタートプラン

### 1週目: 触って慣れる
- 毎日30分、Claude Code に「自分の仕事や生活の面倒な作業」を1つ自動化させる。
  例: 家計簿CSVの集計、画像の一括リサイズ、メール文テンプレ作成。
- `CLAUDE.md` とスキルを1つ作ってみる。

### 2週目: 作品（ポートフォリオ）を3つ作る
- 架空のお店のLPを1つ（Artifactsで公開すればURLで見せられる）
- 業務効率化ツールを1つ（「作業時間が60分→5分」のように**数字**で説明できるもの）
- 記事 or ブログを1つ

### 3週目: 発信と応募
- X / note に「Claude Code で◯◯を作った。こう指示したらこうなった」を毎日投稿。
  SNS経由の依頼はクラウドソーシングより単価が高い傾向がある。
- クラウドワークス / ランサーズ / ココナラで、小さい案件に5〜10件応募。
  ココナラなら「◯◯の自動化ツール作ります」と出品する。

### 4週目: 1件目を納品 → 振り返り
- 納品物は必ず自分で動作確認。`/code-review` で最終チェック。
- 使ったプロンプトと手順をスキル化 → 次の案件は半分の時間でこなせる。
  **時給を上げる＝同じ作業を再利用可能にすること。**

## 「こうしたら良い」コツ

1. **ツールではなく「結果」を売る**: 「AIでサイト作ります」ではなく
   「予約が増えるLPを1週間で」「毎月の集計作業を10分に」。
2. **特定の業種に絞る**: 美容室・整骨院・不動産・士業など。専門にすると単価も紹介も増える。
3. **作業を記録する**: うまくいった指示文を保存 → スキル化 → 発信ネタにもなる（一石三鳥）。
4. **納品後の保守・運用で月額化**: 単発より「月額◯円で更新・改善」の方が安定する。
5. **最新機能を早く試す**: Routines・Artifacts・/design など新機能を使える人はまだ少ない。
   このリポジトリの `daily/` で毎日キャッチアップ。
