# AI管理部 ひな形

Claude を人事・総務・経理・オペレーションの代わりとして動かすための最小セットです。
このフォルダを自分の会社用のリポジトリにコピーして使います。

```
back-office/
├── CLAUDE.md                     会社の基本ルール（最初に書き換える）
├── .claude/skills/               業務ごとの手順書（自動で読み込まれる）
│   ├── morning-brief/SKILL.md    毎朝のまとめ
│   └── monthly-close/SKILL.md    月次締めチェック
├── data/                         CSV・PDFを置く（個人情報はGitに入れない）
└── reports/                      Claude が作ったレポートの保存先
```

## 使い始め方
1. `CLAUDE.md` の【 】を自社の内容に書き換える。
2. Claude Code でこのフォルダを開き、「朝のまとめをして」「先月の月次締めチェックをして」と頼む。
3. うまくいったら「毎朝7時に朝のまとめをするRoutineを作って」と頼み、定期実行にする。
4. 新しい業務は「今やった手順をスキルにして .claude/skills/ に保存して」と頼めば増やせる。

## 注意
- `data/` の給与・マイナンバー・健康情報などは Git に入れない（`.gitignore` 済み）。
- 送信・支払い・提出は必ず人間が行う。
