# 月次締めチェック（スキルのひな形）

## 入力
- `data/請求書/YYYY-MM/` の請求書PDF
- `data/経費/YYYY-MM.csv`（日付, 申請者, 科目, 金額, 領収書有無, 摘要）
- `data/売掛/入金予定.csv`（取引先, 請求日, 金額, 支払期日, 入金日）

## 手順
1. 請求書を読み、取引先・金額・支払期日・インボイス登録番号を表にする。登録番号がないもの、前月と金額が20%以上違うものに印をつける。
2. 経費CSVを CLAUDE.md の経費規程と照合し、上限超過・領収書なし・同日同額の重複疑いを抜き出す。
3. 入金予定CSVから、支払期日を過ぎて未入金のものを抜き出し、督促メールの下書きを作る（送信しない）。
4. 以上をまとめて `reports/YYYY-MM_月次チェック.md` に保存する。

## 出力の形
- 最初に「要対応 ◯件」と3行以内の要約
- 次に 支払予定表 / 経費の指摘 / 未入金 の3つの表
- 最後に「人間が確認・承認すること」のチェックリスト
