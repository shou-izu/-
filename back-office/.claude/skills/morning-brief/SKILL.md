# 朝のブリーフィング（スキルのひな形）

## 手順
1. Gmail の過去24時間の受信を読み、次の3つに分ける。
   - 要返信（相手が返事を待っている）
   - 要対応（支払い・提出・手続きなど、返信以外の作業がある）
   - 情報のみ
2. 要返信には返信の下書きを Gmail に作る。**送信はしない。**
3. Googleカレンダーから今日と明日の予定を取り出し、準備が必要なもの（資料、移動時間）を書き添える。
4. `data/期限一覧.csv` から7日以内の期限を抜き出す。

## 出力の形
- 冒頭: 「今日やること トップ3」
- 表: 要返信 / 要対応 / 予定 / 期限
- 情報のみのメールは件名だけ箇条書き
