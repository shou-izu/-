# 2026-09-28 Claude Code デイリーノート

## 今日のニュース（直近の更新）
- **`claude plugin eval`**（9/7〜11週）: 自作プラグインをテストして、プラグインなしの場合と比較採点できる。
  → プラグインを作って配布・販売したい人向け。品質を数字で示せる。
- **Claude Fable 5.1 が Claude Code で利用可能**（8/31〜9/4週）: 100万トークンの文脈。大きな資料やコードを丸ごと読ませられる。
- **`/skill-doctor`**: 自分のスキルがどれだけ文脈を消費しているか・どれだけ使われているかが分かる。
- **デスクトップの computer use がバックグラウンド動作**（macOS, Pro/Max）: 自分が別作業中でも画面操作を任せられる。

## 今日の使い方Tips
**「まず計画だけ出して」と頼む。**
大きめの依頼（サイト制作、ツール作成）は、いきなり作らせず
「作る前に、ファイル構成と手順の計画だけ出して。私が OK したら実行して」と書く。
認識違いを最初に潰せるので、手戻りと使用量の両方が減る。

## 今日の稼ぐヒント
**作ったものは Artifacts で URL にして見せる。**
ポートフォリオやクライアントへの提案で、「画面のスクショ」より「実際に触れるページ」の方が説得力が段違い。

## 今日の5分アクション
スマホの Claude アプリ（Code タブ）で次を送ってみる:
> 「架空のカフェのLPを1ページのHTMLで作って、Artifactとして公開して」

できたURLがあなたのポートフォリオ第1号です。
