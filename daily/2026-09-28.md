# 2026-09-28 Claude デイリーノート

## 今日のニュース（直近の更新）
- **Cowork の部門別プラグイン**: 人事（内定通知・オンボーディング・評価・報酬分析）、財務、オペレーション向けの既製エージェントがある。
  Gmail・Google Drive・DocuSign などのコネクタと組み合わせて使える。
- **Claude Fable 5.1 が Claude Code で利用可能**（8/31〜9/4週）: 100万トークンの文脈。規程集や1年分の請求データなど、大量の資料をまとめて読ませられる。
- **デスクトップの computer use がバックグラウンド動作**（macOS, Pro/Max）: APIのない勤怠・経費システムへの転記を、自分が別作業中に任せられる。
- **`/skill-doctor`**: 自分のスキルがどれだけ使われているかが分かる。管理部のスキルが増えたら整理に使う。

## 今日の使い方Tips
**数字を出させるときは「根拠も付けて」と必ず書く。**
例: 「この経費CSVを科目別に合計して。各合計には、元の行番号と計算式を付けて」
確認が速くなり、間違いがあってもすぐ見つかります。

## 今日の稼ぐヒント
**「◯時間 → ◯分」を記録しておく。**
自分の管理業務で減った時間は、そのまま他社に「AI管理部」を売るときの一番強い材料になります。
