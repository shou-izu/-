# 影響のわかりやすい要約と今後の対策（2026年9月27日時点）

> 元レポート：[2026-09-27.md](2026-09-27.md)
> 【事実】は元レポートの出典に基づくもの、【見解】【対策】は分析・提案です。対策は立場別に書いています。

---

## 1. ひとことで言うと

**「家を建てる人の財布は細り、建てる側は人もお金も足りず、電気代は上がる。ただし、省エネ・防災・電力インフラの分野には追い風が吹いている」**という状況です。

---

## 2. 影響を与えている7つの要因

| # | 要因 | 何が起きているか【事実】 | 誰にどう効くか【見解】 |
|---|---|---|---|
| ① | **金利上昇** | 日銀が政策金利を1.25%へ引き上げ（9/18）。変動金利は0.9〜1.2%台で、今回の利上げ分はまだ反映前 | 住宅ローンの返済額が増える → 注文住宅（持家）の需要が減る。賃貸にとっては追い風 |
| ② | **建築コストの高止まり** | 資材は2021年比で約+38%。公共工事の労務単価は+4.5%（25,834円） | 住宅価格が上がり続ける。値上げを価格に転嫁できない会社は利益が削られる |
| ③ | **人手不足・働き方規制** | 大手・中堅の約7割が「今年度は大型工事を新たに受けられない」。建設業の倒産は8月だけで182件（+18%） | 「仕事はあるのに回せない」。工期の長期化と中小業者の淘汰が進む |
| ④ | **電気代の上昇** | 補助は9月使用分で終了。11月に届く請求から4人世帯で月約2,450円上がる | 家計の負担が増える。省エネ住宅・太陽光・蓄電池の経済的な価値が上がる |
| ⑤ | **政策の選別** | 住宅補助は省エネ性能の高い住宅に集中（2027年度要求3,030億円）。国土強靱化は約4.1兆円 | 「高性能住宅」と「公共土木・防災」に予算が集まり、それ以外は支援が薄い |
| ⑥ | **災害の激甚化** | 台風25号で北印旛沼の堤防が決壊。新国交相は「最優先は災害対応」と表明 | 復旧工事の需要が増える一方、人員の奪い合いが起きる。防災性能の高い住宅のニーズが高まる |
| ⑦ | **電力需要の増加** | データセンター向けに電力8社が約30カ所で送電網を増強。原発は11基が稼働中 | 電気工事・設備工事の需要が増える。中長期的には電気料金の上昇圧力になる |

### 要因のつながり（イメージ）

```
金利↑ ──→ ローン負担↑ ──→ 持家需要↓ ──┐
資材・人件費↑ ──→ 住宅価格↑ ─────────┼──→ 中小工務店・下請けの経営悪化・倒産増
人手不足 ──→ 工期長期化・受注制約 ───┘
電気代↑ ──→ 光熱費負担↑ ──→「省エネ・創エネ住宅」の価値↑ ←── 政策の補助が集中
災害・DC需要 ──→ 公共土木・電気設備工事の需要↑（ただし人手の取り合い）
```

### 家計への影響の目安（試算）【見解】
- **住宅ローン**：3,000万円・35年・元利均等で計算すると、金利1.0%で月84,686円、1.25%で月88,226円（**月+約3,500円、年+約4.2万円**）。1.5%になると月91,855円です。
- **電気代**：4人以上の世帯で月約2,450円、**年約2.9万円**の負担増（補助ゼロの月で換算）。
- この2つを合わせると、**年7万円前後の負担増**になり得ます。住宅を買うかどうかの判断や、予算の上限に効いてくる規模です。

## 3. 立場別の今後の対策

### A. ハウスメーカー・工務店

| 時期 | 対策 |
|---|---|
| **今すぐ** | **「光熱費込みの総コスト」で提案する**：ローン返済額と電気代を合わせた月額で比べる資料を作る。高断熱・太陽光・蓄電池の住宅は「電気代＋金利上昇」への備えとして訴求できる |
| **今すぐ** | **補助金を取りこぼさない**：みらいエコ住宅（ZEH・GX志向型）の要件を満たす標準仕様を整え、申請体制を用意する。2027年度も同規模の予算が要求されている |
| **半年以内** | **金利上昇に備えた顧客提案**：固定金利・ミックス型ローンの比較、無理のない借入額のシミュレーションを営業の標準手順にする |
| **半年以内** | **価格改定のルール化**：資材価格に連動する条項（スライド条項）を契約に入れ、見積もりの有効期限を短くする |
| **1〜3年** | **収益源の分散**：リフォーム（省エネ改修の補助が拡充傾向）、賃貸住宅、防災性能の高い住宅、建て替え需要へシフトする |
| **1〜3年** | **施工体制の確保**：協力業者の囲い込み（発注量の平準化・支払条件の改善）、プレカット・パネル化による現場作業の削減 |

### B. 建設会社（ゼネコン・専門工事業者）

| 時期 | 対策 |
|---|---|
| **今すぐ** | **受注の選別**：利益率と工期に余裕のある案件を優先し、赤字リスクのある大型案件は無理に取らない |
| **今すぐ** | **価格転嫁の交渉**：労務単価の上昇（+4.5%）と資材高を根拠に、発注者へ契約変更・単価見直しを申し入れる。国の「適正な請負代金」ルールを活用する |
| **半年以内** | **災害復旧・国土強靱化案件への備え**：台風25号の復旧と、補正予算で見込まれる公共工事に向けて、入札参加資格・人員計画を準備する |
| **1〜3年** | **省人化投資**：ICT施工・ドローン測量・AI（全建は2029年度に会員の40%で活用が目標）、BIM/CIMを導入する。IT導入補助金なども活用する |
| **1〜3年** | **人材確保**：週休2日・賃上げ・外国人材（育成就労制度）の受け入れ体制を整える。後継者不在の場合は、M&Aや事業承継も選択肢になる |

### C. 電気工事・設備・エネルギー関連

| 時期 | 対策 |
|---|---|
| **今すぐ** | **住宅向け「太陽光＋蓄電池＋HEMS」提案の強化**：補助終了による電気代上昇が、需要のきっかけになる |
| **半年以内** | **データセンター・送電網関連の案件へ参入準備**：GX戦略地域（北海道・東北・九州など9地域）で需要が集中する見込み |
| **1〜3年** | **有資格者の育成**：電気工事士・電気主任技術者の不足が制約になるため、資格取得の支援を行う |

### D. 家を建てる・持っている個人

| 時期 | 対策 |
|---|---|
| **今すぐ** | **ローンの見直し**：変動金利の人は、1.5〜2%まで上がった場合の返済額を試算し、繰上返済や固定金利への切り替えを検討する |
| **今すぐ** | **電気の契約の見直し**：プランや電力会社を比較し、節電・省エネ家電を検討する |
| **これから建てる人** | **「建築費＋30年分の光熱費」で比べる**：断熱性能（等級5以上）と太陽光を重視し、補助金の対象になる仕様を選ぶ。**施工会社の経営状態**（完成保証の有無）も確認する |
| **災害への備え** | ハザードマップで立地を確認し、地震・水災の保険補償と、蓄電池などの停電対策を見直す |

## 5. 注意事項
- 上記の試算は単純化したモデル（3,000万円・35年・元利均等・手数料等は除く）です。
- 対策は一般的な方向性です。個別の資金計画・経営判断は、金融機関・専門家への確認をおすすめします。
- 政策（補助金・税制）は臨時国会の動向で変わる可能性があるため、日次レポートで随時更新します。
