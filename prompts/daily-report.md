# デイリーレポート作成手順（毎日の自動実行用）

リポジトリ `shou-izu/-` のブランチ `claude/daily-construction-energy-report-snwk3n` で作業する。

1. WebSearch で直近24〜48時間を中心に、以下3分野の最新情報を調べる（日本国内中心、必要に応じて海外）。
   - ハウスメーカー・住宅市場（住宅着工統計、大手HM決算・受注速報、住宅ローン金利、住宅政策・補助金、倒産）
   - 建設業（倒産・人手不足、資材・労務単価、公共投資・国土強靱化、災害復旧、主要ゼネコン動向、制度改正）
   - 電気（電気料金・補助、原発再稼働、再エネ、送電網・データセンター需要、エネルギー政策）
   - 横断：政治（内閣・国会・予算・税制）、日銀の金融政策
2. `reports/YYYY-MM-DD.md`（日本時間の日付）に、`reports/2026-09-27.md` と同じ構成で書く。
   - 0. 今日のヘッドライン（3行）／1. ハウスメーカー／2. 建設業／3. 電気／4. 政治・政策／5. 今後の注目日程／6. 影響と対策（わかりやすく）／出典
   - 「6. 影響と対策」は `reports/2026-09-27-impact-and-actions.md` の考え方に沿って、その日の動きが誰に（ハウスメーカー・工務店／建設会社／電気工事・エネルギー事業者／個人）どう効くかを平易に書き、立場別の対策を「今すぐ／半年以内／1〜3年」で簡潔に示す。前回から変化がない対策は繰り返さず、変更点だけ書く。
   - 各章は **【事実】**（出典のある情報のみ・数値と日付を明記）と **【見解】**（分析・見通し）を必ず分ける。
   - 推測や未確認情報を事実として書かない。報道間で数値が食い違う場合はその旨を書く。
   - 前日のレポートと同じ内容の繰り返しは避け、新しい動きを優先する（変化がない分野は「特段の新規動向なし」と簡潔に）。
3. `README.md` のレポート一覧に当日分を追記する。
4. コミットしてブランチに push する（`git push -u origin claude/daily-construction-energy-report-snwk3n`）。
5. 最後に、ヘッドライン3行とレポートへのリンクを返答として出力する。
